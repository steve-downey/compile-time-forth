* Examples of Transclusion

This file predates the real =smd::forth= compiler (docs/forth-plan.md) and
originally transcluded a bootstrap placeholder API removed outright in
Step F15 (see =handoff.md='s "Step F15" section): a =forth::forth()=
free function returning the literal string "Steve", declared in
=forth.hpp=, defined in =forth.cpp=, tested in =forth.test.cpp=, and
printed by the =hello= example.

Step F15 replaced that placeholder with the real public one-shot API
(=smd::forth::compiled_forth<Source>=, =smd::forth::source_literal=,
=smd::forth::forth_program=), which is header-only -- there is no longer a
separate =forth.cpp= "definition" file for a second anchor to point at.

(=44cc988c-7353-43aa-a7d3-8840f92371a6=,
=a66dec0e-e5cc-44b5-b9f1-bbed787c3d44=,
